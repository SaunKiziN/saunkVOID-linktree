## 🌌 Sobre o projeto

O **SaunK VOID** é meu hub pessoal de links.

A proposta não era criar apenas uma lista de botões, mas transformar uma página simples de links em uma experiência que carregasse minha identidade visual.

O projeto reúne em um único lugar meus principais canais de conteúdo, comunidade, redes sociais e contato profissional, utilizando uma interface inspirada em uma estética espacial e minimalista.

---

## ✨ Experiência

Ao acessar o site, o usuário encontra uma tela inicial com a identidade **SaunK — Echoes in the Void** e pode entrar no hub através da transição **Enter the Void**.

A interface utiliza elementos visuais e interativos para dar personalidade à navegação:

- fundo cósmico animado;
- partículas e elementos espaciais;
- animações e efeitos de hover;
- transições suaves entre as seções;
- interface responsiva;
- efeitos sonoros de interação;
- música ambiente opcional;
- controles independentes para **SFX** e **música**.

## 🔊 Sistema de áudio

O projeto possui uma camada de áudio própria para complementar a experiência visual.

Os efeitos de interface são gerados utilizando a **Web Audio API**, incluindo sons para hover e clique nos elementos interativos.

A música ambiente possui:

- ativação manual;
- reprodução em loop;
- fade in e fade out;
- pausa automática ao sair da aba;
- retomada suave ao voltar para a página;
- controle independente dos efeitos sonoros.

Tanto a música quanto os efeitos podem ser ativados ou desativados pelo usuário.

### Principais componentes

**`Hero`**  
Responsável pela introdução do site, identidade visual e entrada para o VOID.

**`LinkButtons`**  
Organiza e renderiza os diferentes grupos de links.

**`CosmicBackground`**  
Controla partículas, galáxias, ondas e elementos que formam o fundo animado.

**`AudioProvider`**  
Gerencia efeitos sonoros, música ambiente e estados globais de áudio.

**`SoundToggle`**  
Permite controlar individualmente música e efeitos sonoros.

## 💻 Rodando localmente

Clone o repositório:

```bash
git clone https://github.com/SaunKiziN/saunkVOID-linktree.git
```

Entre na pasta do projeto:

```bash
cd saunkVOID-linktree
```

Instale as dependências:

```bash
npm install
```

Inicie o ambiente de desenvolvimento:

```bash
npm run dev
```

Depois, acesse:

```text
http://localhost:3000
```
